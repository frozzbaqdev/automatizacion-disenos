# Directrices del proyecto

- Después de cualquier cambio en `src/` (código o diseño), publica automáticamente con `npm run deploy` sin esperar confirmación explícita del usuario. `clasp` ya está autenticado en esta máquina y el deploy usa un ID de deployment fijo, así que la URL `/exec` no cambia.
- No uses Playwright (ni ninguna herramienta de automatización de navegador) a menos que el usuario lo pida explícitamente.
